# 🏁 Iron Circuit

**A fast, weapon-packed racing game for PC and Android.**
Drift through corners, hit nitro, fire weapons at your rivals, and race through Career and Story modes, solo or with friends over Wi-Fi.

[⬇️ **Download the latest version**](../../releases/latest) · [🐞 Report a bug](../../issues/new/choose) · [💬 Join the discussion](../../discussions)

## ⬇️ Download

Open the **[Releases page](../../releases/latest)** and download the file for your device:

| Platform | File | Notes |
| --- | --- | --- |
| 🖥️ Windows PC | `.exe` | Run it directly |
| 📱 Android | `.apk` | See the install steps below |

### Installing on Android
1. Download the `.apk` file on your phone.
2. Open it. If Android asks, allow **Install unknown apps** for your browser or file manager.
3. Tap **Install**, then open **Iron Circuit**.

Every update is signed with the same key, so a new APK installs **over** the old one and your progress stays.

### Running on Windows
1. Download the `.exe` and double-click it.
2. If Windows shows **"Windows protected your PC"**, click **More info → Run anyway**. This warning appears because the game comes from an independent developer and is not code-signed.

## ✨ Features

- 🏎️ **Career and Story modes**
- 💨 **Drifting and nitro** for tight corners and big speed boosts
- 🔫 **Front and rear weapons** to take down rivals
- ⚡ **Unique car skills** you can trigger mid-race
- 📶 **Wi-Fi multiplayer** and team play on the same network
- 🎮 **Two mobile control styles:** easy **SIMPLE** mode and full **PRO** mode

## 🎮 Controls

> 💡 **In-game help:** Open **How to Play** from the main menu for step-by-step instructions on both phone and PC. On phones, your first race also shows quick tips for the controls you're using.

### 📱 Mobile: SIMPLE mode (default)

Your car **accelerates by itself**, so you can start racing in seconds.

| Action | How |
| --- | --- |
| Steer | Hold the **left** or **right half** of the screen (or use **tilt**) |
| Brake | **BRAKE** button (bottom-left) |
| Drift | **DRIFT** button, next to BRAKE. Hold while turning, release for a drift boost |
| Fire front weapon | **FIRE** button (bottom-right) |
| Drop rear weapon | **REAR** button, above FIRE |
| Nitro | **NITRO** button, or swipe **up** anywhere on the screen |
| Car skill | Swipe **down** anywhere (the HUD shows *READY · SWIPE DOWN*) |
| Pause / camera | Pause button at the top, then **CAMERA** |

### 📱 Mobile: PRO mode
Every control is its own button: steering wheel (or arrows), GAS, BRAKE, DRIFT, NITRO, FIRE, REAR, SKILL, CAM and BACK.

- Switch modes in **Settings → PHONE CONTROLS**: *SIMPLE* / *PRO* / *PRO + AUTO-GAS*.
- Choose how you steer in **Settings → PHONE STEERING**: tap sides or tilt (SIMPLE), wheel, buttons or tilt (PRO).
- Use **CUSTOMIZE BUTTONS** (in Settings or the pause menu) to move and resize buttons.

### 🖥️ PC
Open **How to Play** from the main menu to see all the PC controls, the same place that explains the phone controls.

## 📶 Playing with friends (Wi-Fi)

1. Connect all devices to the **same Wi-Fi network**.
2. One player hosts a race and the others join.
3. Everyone should use a compatible version. Check the release notes if you can't connect.
